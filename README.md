# Aura — Documentation

Aura is a feature-rich Discord music bot supporting multi-platform playback — YouTube, Spotify, SoundCloud, Deezer, and JioSaavn — along with custom playlists, liked songs, audio filters, autoplay, 24/7 voice mode, and per-server configuration.

This repository hosts Aura's public documentation, including its Terms of Service and Privacy Policy.

- [Terms of Service](./TERMS_OF_SERVICE.md)
- [Privacy Policy](./PRIVACY_POLICY.md)

## ✨ Features
- Multi-source music playback: YouTube, Spotify, SoundCloud, Deezer, JioSaavn
- Custom playlists & liked songs, saved per user
- Autoplay & stackable audio filters (bass boost, nightcore, 8D, and more)
- 24/7 voice connection mode
- Slash commands, prefix commands, and no-prefix mode
- Per-server configuration (custom prefix, ignored channels, auto-react/auto-respond)
- Optional premium features
